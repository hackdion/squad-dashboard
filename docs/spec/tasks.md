# NEXUS AI · Demo 执行清单

目标：在 1024 程序员节现场，用最短路径交付一个可在线访问、可讲解、可交互的五人开黑战术工作台 Demo。范围锁定两个核心页（总览 + 战术指挥中心），其余 P0 页面做轻量可用版本。

## 一、从交付包提炼的硬要求

| 类别 | 要求 | Demo 落地方式 |
| --- | --- | --- |
| 视觉 | 深蓝黑底、毛玻璃仅做分层、青色战术高亮、金色关键按钮、1px 描边 | `tokens.css` 固化色板与尺度，所有页面复用 |
| 数据 | 固定样本 28 场 / 18 胜 10 负 / 367 杀 280 死 / 119,840 分 | `src/data/matches.json`，指标全部由明细派生 |
| 诚信 | 标注「演示模式」；不伪装真实 AI、语音、在线人数 | 全站演示徽标；语音波形标注“模拟”；分析标注“演示规则生成” |
| 地图 | 自绘 Café-Sim，B1/1F/2F，A/B 点，只沿有效边规划 | 归一化坐标 + 房间/节点/边数据，SVG 渲染，跨层在楼梯中断 |
| 回放 | 五阶段、统一时钟、拖拽/倍速/重置可复现 | rAF 单时钟，0.5x/1x/2x，时间轴与阶段磁贴联动 |
| 响应式 | 1440 基准，兼容 1280/1024/768/390；小屏切标签页 | CSS 网格 + <900px 三标签（情报/地图/方案） |
| 自定义 | 卡片顺序/显隐、队名、强调色、持久化、恢复默认 | `NexusProvider` + localStorage，自定义页与首页联动 |

## 二、执行步骤与状态

1. **工程与设计系统**：Vite + React 19 + TS，HashRouter（无第三方路由），本地 Rajdhani 字体，CSS tokens，AppShell（侧栏 + 顶栏 + 演示状态）。✅
2. **数据与指标**：对局 fixtures、干员 13 人、小队 5 人、地图 4 张；胜率 / K/D / 平均分 / 趋势 / 定位 / 雷达 / 地图表现同源计算。✅
3. **总览首页**：英雄横幅、五人卡、KPI、双轴趋势、定位环图、五维雷达、地图表现、最近对局、卡片自定义联动。⏳ 子代理实现中
4. **战术指挥中心**：左情报流（预设播放/手输/确认/删除）、中地图（缩放拖拽、楼层、图层、A/D/R/E 图例）、五阶段回放、右四标签（综合/干员/方案/风险）、方案失效与重新生成、应用状态机。✅
5. **辅助页**：我的小队（阵容检查）、干员库（筛选/搜索/加入阵容）、地图分析、战绩（筛选/新增/删除撤销）。⏳ 子代理实现中
6. **自定义页**：卡片顺序与显隐、队名/标语、强调色白名单、恢复默认、导入导出与 schemaVersion。⏳
7. **验证与发布**：本地 1440/390 两种宽度截图检查；`npm run build`；GitHub Actions → Pages，线上复验深链 `#/tactical`。⏳

## 三、验收口径

- 首页任意筛选切换后，KPI、趋势、地图卡、最近对局同步变化，且四项指标能由 28 场明细复算。
- 战术页默认展示 2F 已应用路线；拖动时间轴到 45s/65s，队员位置与阶段一致；暂停后位置保持；重置为 0。
- 切换攻防/目标后旧方案失效、应用按钮禁用；重新生成后恢复可应用。
- 楼层切换不改变全局时间；跨层路线在楼梯节点断开并提示切层。
- 390px 下情报/地图/方案为标签切换，地图可读、无横向溢出。
- 所有“AI/语音/在线”表述均带演示限定，不出现真实服务能力宣称。

## 四、演示脚本（90 秒）

1. 打开总览：报队名与五人阵容 → 切「近 7 天」看趋势重算 → 点「开始行动」。
2. 战术页：先是 2F 已应用的西侧主攻路线 → 播放回放，看队员沿路线推进。
3. 左栏点「播放预设情报」，第 3 条情报进流 → 点确认，右栏标记“待复核”。
4. 切「防守」→ 方案失效提示 → 重新生成 → 应用防守方案，展示 D 点与回防虚线。
5. 打开「自定义」改强调色与卡片显隐 → 回首页展示即时生效与持久化。
